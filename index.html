~/projekte

  • ├── simlang/ Sprache

    Eigene Programmiersprache (Kürzel SL, Dateiendung .sl) — bewusst ohne OOP. Erkennt und startet .sl-Dateien automatisch. Eine objektorientierte Schwestersprache (OSL) ist geplant.

    github.com/VTL-Labs/SimLang
  • ├── wpf-calculator/ Windows-App

    Meine erste veröffentlichte Windows-Anwendung. Die Rechenengine wird nach und nach durch SimLang ersetzt.

    github.com/VTL-Labs/WpfCalculator
  • ├── path-between-gods/ Unity

    Spielprojekt in Unity, als Monorepo aufgebaut — das Unity-Projekt liegt als eigener Unterordner im Repository statt im Root.

    github.com/VTL-Labs/path-between-gods
  • ├── neuronales-netzwerk/ Python

    Ein neuronales Netz komplett selbst in Python geschrieben, ohne Frameworks wie TensorFlow. Ziel: die logische XOR-Funktion lernen.

    github.com/VTL-Labs/neuronales-netzwerk
  • └── stimmungsmessung/ Schulprojekt

    Digitale Stimmungsmessung für den Geschichtsunterricht: HTML/CSS/JS-Frontend, Flask-Backend und ein Raspberry Pi 4 als lokaler Server ohne Internetanbindung.

    github.com/VTL-Labs/stimmungsmessung
